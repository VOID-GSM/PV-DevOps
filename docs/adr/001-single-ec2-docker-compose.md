# 001. 단일 EC2 + Docker Compose로 운영
Status : Accepted
Date : 2026-10

## Context
사용자는 동아리 부원 수십명 이내의 규모이고 트래픽은 낮고 예측이 가능하다. 운영 인원은 1명이고 월 예산은 **$30 이내**로 잡았다. **백엔드**와 **DB** 두 컨테이너만 운영하면 된다.

## Decision
**EC2 t4g.small(ARM, 2GB)** 한 대에서 Docker Compose로 백엔드와 PostgreSQL을 함께 운영한다.

## Alternatives
대안 | 버린 이유
--- | ---
ECS Fargate + RDS | 태스크·RDS·ALB 비용이 더해져 월 비용이 현재의 2~3배 이상. 이 규모에서 얻는 이점(무중단, 자동 확장)이 비용을 정당화하지 못함
EKS | 컨트롤 플레인만 월 $70 이상. 운영 복잡도가 규모에 비해 과함 
RDS 분리 | 월 $15 이상 추가. 백업은 AWS Backup EBS 스냅샷으로 대체 

## Consequences
**얻은 것** : 월 약 $22로 전체 서비스 운영. 구성이 단순해 장애 원인을 찾기 쉬움.

**감수한 것** : 
- **단일 장애점** : 서버가 죽으면 전체가 멈춤 → EC2 상태 검사 실패 시 자동 복구, 헬스체크 알림으로 보완한다.
- **배포 중 짧은 중단** : 컨테이너 교체 동안 수 초~수십 초 응답이 없을 수 있다.
- **DB가 같은 서버에 있음** : 데이터는 별도 EBS 볼륨에 두고 매일 스냅샷(7일 보관)

**다시 검조할 시점** : 무중단 배포가 필요해지거나 서버 한대로 부하를 감당하지 못할 때
